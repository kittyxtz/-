# Созвон

Интерактивный прототип сервиса видеовстреч. Визуальный референс — предоставленный HTML: двухчастная композиция, синий акцент, мягкие формы. Самостоятельное оформление: светлая палитра, воздушная иллюстрация, собственные тексты и сценарии.

## Локальный запуск

Требуется Node.js 22 или новее. Зависимостей нет.

```powershell
npm start
```

Откройте http://127.0.0.1:4185. Проверка JavaScript: `npm run check`.

## Возможности

- Создание демонстрационной встречи и вход по ссылке или коду.
- Локальная проверка камеры и микрофона, показ экрана.
- Сохранение запланированных встреч в localStorage и экспорт приглашений .ics.
- Широкое модальное окно «Мои встречи»: календарь месяца, список выбранного дня с прокруткой, добавление встречи и копирование ссылки. Отдельный адрес `meetings.html` сохраняется для прямого входа.
- Собственные окна выбора даты и времени: месяцы плавно перелистываются, часы и минуты выбираются прокруткой, нажатием или стрелками клавиатуры.
- Светлая и тёмная темы, адаптация под узкие экраны, клавиатурная навигация.
- Отдельная страница `profile.html`: имя, подпись и цвет аватара сохраняются в браузере. Имя подставляется в форму встречи, аватар используется в подготовке и комнате.

Верх рекламной страницы состоит из двух панелей. Ниже — сценарии использования для работы, близких и идей, конкретные удобства и финальное приглашение начать встречу. Название встречи раскрывается по желанию. «Мои встречи» находятся в центре компактного хедера, профиль — справа.

Камера и микрофон изначально выключены и запрашиваются только по нажатию соответствующей кнопки. Закрытие подготовки или выход из комнаты останавливает медиапотоки. Видеосвязь между участниками, сервер сигналинга, TURN и облачное хранение не подключены. Интерфейс обозначает комнаты как демонстрационные.

## Иллюстрация

`dist/assets/air-ribbon.webp` — оптимизированный рабочий файл. PNG-оригинал: `dist/assets/air-ribbon.png`. Создан встроенным ImageGen. Промпт: абстрактная полупрозрачная лента из белой органзы, свободно парящая открытой петлёй на небесно-голубом фоне; мягкий дневной свет; ощущение воздуха, свободы и лёгкости общения; без текста, логотипов и людей.

Локальные шрифты Inter Tight извлечены из предоставленного референса. Сборка не зависит от внешних CDN.


Широкий экран использует заново сгенерированное продолжение кольца `air-ribbon-extended.webp`. При расположении панелей друг под другом (до 760 px) отображается исходный квадратный `air-ribbon.webp`. Подробности и точный промпт — ASSET-NOTES.md.

В нижнем блоке «Встречайте людей. Не настройки.» можно открыть демокомнату и осмотреться. Иконки на главной и в профиле обновлены единым набором векторных знаков с лёгкой заливкой. Панель встречи имеет горизонтальный сдвиг вкладок и не содержит дополнительных стрелок и подписи об устройствах.


Планирование теперь открывается внутри панели встречи как третий экран с выездом снизу. Закрывается кнопкой «Назад» и Escape. Имя встречи раскрывается анимированным выездом поля. Нижний предпросмотр показывает имя из профиля и содержит действия проверки устройств, ведущие в демокомнату без автоматического включения камеры или микрофона.
