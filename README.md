# Созвон

Интерактивный дизайн-прототип видеовстреч и чатов на React и Vite. Интерфейс адаптирован для компьютера и телефона. Бэкенд не подключён: профиль, настройки, встречи и переписки сохраняются локально в браузере.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm install
npm start
```

Сайт доступен по адресу `http://127.0.0.1:4185`. Сервер разработки поддерживает горячее обновление.

```sh
npm run check    # Тесты и production-сборка
npm run build    # Сборка в dist/
npm run preview  # Просмотр сборки на http://127.0.0.1:4186
```

Папку `dist/` можно разместить на статическом хостинге.

## Страницы

| Адрес | Содержимое |
| --- | --- |
| `index.html` | Главная, создание встречи, вход по ссылке и планирование |
| `chats.html` | Личные и групповые чаты, профили и материалы переписок |
| `meetings.html` | Календарь встреч; на компьютере также открывается панелью из навигации |
| `profile.html` | Настройки профиля, устройств, уведомлений и оформления |
| `auth.html` | Формы входа, регистрации и восстановления доступа |
| `guest.html` | Гостевой вход во встречу |
| `meeting.html` | Демонстрационная комната встречи |

## Возможности интерфейса

- Адаптивная навигация, плавные переходы и поддержка уменьшенного движения.
- Календарь с выбором даты и времени, редактированием встреч и перелистыванием месяцев пальцем.
- Чаты с черновиками, поиском по тексту, дате и участнику группы, ответами, пересылкой, закреплением и контекстными меню.
- Вложения, просмотр фотографий с исходными пропорциями и вставка изображений из буфера обмена.
- Запись голосового удержанием: отпускание отправляет, движение вверх закрепляет запись, влево — отменяет. Волны строятся по настоящему аудиосигналу.
- Мобильные жесты: вправо — выход из чата, влево по сообщению — ответ. Вкладки материалов профиля перелистываются как страницы.
- Профили с активностью участников, тегами владельца и администратора, контактами и вкладками доступных материалов.
- Проверка камеры, микрофона и демонстрации экрана через браузерные API.
- Темы оформления, настройки устройств и локальное сохранение данных.

Формы авторизации демонстрируют клиентскую проверку и состояния интерфейса. Серверная авторизация, доставка сообщений, реальная синхронизация активности и связь между участниками не реализованы. Состав участников и их роли в примерах заданы демонстрационными данными.

## Структура проекта

- `src/pages/` — страницы приложения.
- `src/components/` — элементы интерфейса, формы, календарь и чат.
- `src/lib/` — хранение данных, жесты, анимации, работа со звуком и вспомогательная логика.
- `src/styles/` — стили и адаптивные правила.
- `public/` — шрифты, иллюстрации и статические файлы.
- `tests/` — тесты логики дат, встреч, сообщений, тем, аудио и жестов.
- `dist/` — готовая production-сборка.

Локальные проверочные страницы и снимки в `artifacts/` исключены из Git.
